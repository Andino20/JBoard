# JBoard

## Overview

This project is a **Java-based framework for creating 2D board games**.

## Features

* Object-oriented board game components
* Input handling for mouse and keyboard interactions
* Basic rendering using Java 2D
* Networking for online play

## Project Structure

```
.
├── jboard/         # Board game framework
└── examples/       # Example games using the framework
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone git@github.com:Andino20/JBoard.git
   ```
2. Open the project in your preferred Java IDE.
3. Run `./gradlew build` for building the framework and the examples.
4. Run `./gradlew examples:maedn:run` to start the Ludo (_Mensch-ärgere-dich-nicht!_) demo game.

## Requirements

* Java 21 or higher
* Gradle (optional, for builds)
